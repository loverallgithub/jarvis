2. YOUTUBE DATA API KEY  (free, ~10 min, no card — unblocks 7 connectors)
-------------------------------------------------------------------------
Full runbook: /opt/jarvis/runbooks/HT-002-youtube-data-api-key.md

  a. https://console.cloud.google.com -> Select a project -> New Project.
     Name: jarvis-product-development
  b. APIs & Services -> Library -> search "YouTube Data API v3" -> ENABLE.
     (Do not skip. A key without this returns a 403 that looks exactly
     like a bad key.)
  c. APIs & Services -> Credentials -> Create Credentials -> API key.
     The key starts with "AIza".
  d. RESTRICT the key: API restrictions -> Restrict key ->
     YouTube Data API v3. Leave application restrictions = None.

  Install (replace AIza... with your real key):
    $ printf 'JPD_YOUTUBE_API_KEY=%s\n' 'AIza...' >> /opt/jarvis/platform/docker/.env
    $ chmod 600 /opt/jarvis/platform/docker/.env
    $ docker service update --env-add JPD_YOUTUBE_API_KEY='AIza...' jarvis_core
    $ docker service update --env-add JPD_YOUTUBE_API_KEY='AIza...' jarvis_console
  (--env-add is required: restarting a service does NOT re-read the .env file.)

  Then set each channel's handle — read it off the channel's own URL
  (youtube.com/@Handle). DO NOT guess from display names; a wrong handle
  returns empty results, not an error. Channels needed:
    Alex Hormozi, Leila Hormozi, Codie Sanchez,
    Liam Ottley, Liam Evans, Jack Roberts
  Paste the six handles into a Claude session (it will prepare the SQL), or
  use the UPDATE template in the HT-002 runbook.

  Verify:
    $ /opt/jarvis/bin/jpd connectors check youtube_data_v3   # expect: live
    $ /opt/jarvis/bin/jpd connectors harvest yt_alex_hormozi # expect: >0 signals
    $ /opt/jarvis/bin/jpd connectors                         # expect: 10 live -> 17


3. REDDIT OAUTH  (fixes the connector with 866 recorded failures)
-----------------------------------------------------------------
Reddit blocks this datacenter IP for anonymous requests; OAuth is the fix.

  a. Log into Reddit -> https://www.reddit.com/prefs/apps
  b. Bottom of the page: "create another app"
       type:          script
       name:          jarvis-jpd
       redirect uri:  http://localhost:8080   (required by the form, unused)
  c. After creating:
       client ID  = the short string directly under the app name
       secret     = the field labelled "secret"

  Install (same pattern as above):
    $ printf 'JPD_REDDIT_CLIENT_ID=%s\n'     'PASTE_ID'     >> /opt/jarvis/platform/docker/.env
    $ printf 'JPD_REDDIT_CLIENT_SECRET=%s\n' 'PASTE_SECRET' >> /opt/jarvis/platform/docker/.env
    $ docker service update --env-add JPD_REDDIT_CLIENT_ID='PASTE_ID' --env-add JPD_REDDIT_CLIENT_SECRET='PASTE_SECRET' jarvis_core
    $ docker service update --env-add JPD_REDDIT_CLIENT_ID='PASTE_ID' --env-add JPD_REDDIT_CLIENT_SECRET='PASTE_SECRET' jarvis_console

  NOTE: the reddit connector is currently a stub that raises with a reason.
  Once the creds are installed, tell Claude "implement the reddit OAuth
  connector" — it is a code change + tests + deploy (~30 min).
